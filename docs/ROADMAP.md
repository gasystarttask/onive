# Roadmap – Malagasy LLM

## Phase 1: Data (Weeks 1–2)
- Collect Malagasy corpora (Wikipedia, OSCAR, JW300, Tatoeba)
- Clean, deduplicate, LangID filter
- Release cleaned dataset

## Phase 2: Language Adaptation (Weeks 3–4)
- LAFT on monolingual Malagasy
- Release base adapted checkpoint

## Phase 3: Instruction Tuning (Weeks 5–6)
- Curate instruction dataset (chat, QA, summarization)
- Train LoRA adapter
- Release first conversational model

## Phase 4: Domain Packs (Weeks 7–8)
- Medical pack: prescription + consultation transcription
- Meetings pack: workshop/agenda summarization
- Evaluation (BLEU, Rouge, human feedback)

## Phase 5: Public Demo
- Deploy demo on HF Spaces
- Invite community contributions
